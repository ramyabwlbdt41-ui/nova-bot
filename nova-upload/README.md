# ✨ نوفا — بوت ذكاء اصطناعي عربي مجاني

بوت تيليجرام بتجربة "مميزة": تأثيرات حركية، رياكشنات، ملصقات، وواجهة عربية أنيقة — **مجاني بالكامل، بدون دفع**.

---

## 🚀 التشغيل

```bat
pip install -r requirements.txt
run.bat
```

التوكن مضبوط مسبقاً في `config.py`.

---

## 🆔 تفعيل لوحة الإدارة (خطوة واحدة)

1. افتح البوت وأرسل `/id`
2. انسخ الرقم وضعه في `config.py`:
```python
ADMIN_IDS = [123456789]
```
3. أعد تشغيل البوت

## 🧠 الذكاء الاصطناعي — كيف يعمل الآن

### الوضع الحالي: مجاني تماماً بدون مفتاح
يستخدم مزوّداً مجانياً مفتوحاً. القيد: **رسالة واحدة كل ~45 ثانية لكل جهاز**.
البوت يخفي هذا بطابور ذكي ورسالة انتظار، لكنه غير مناسب لعدد كبير من المستخدمين.

### الترقية (دقيقتان، مجاناً، بدون بطاقة)

أسهل طريقة: من داخل البوت (أنت الأدمن) أرسل:

```
/setkey gemini AIza...
```

البوت يختبر المفتاح ويحفظه ويشغّل الوضع السريع فوراً — بدون تعديل ملفات.

المزوّدون المتاحون: `gemini` · `groq` · `openrouter`


| المزوّد | الرابط | الحد المجاني |
|---|---|---|
| **Google Gemini** ⭐ الأسهل | https://aistudio.google.com/apikey | سخي جداً، عربي ممتاز |
| **Groq** ⭐ الأسرع | https://console.groq.com/keys | 1000 طلب/يوم |
| **OpenRouter** | https://openrouter.ai/keys | موديلات `:free` |

مثال Gemini:
```python
AI_KEY = "AIza..."
AI_BASE = "https://generativelanguage.googleapis.com/v1beta/openai/"
AI_MODELS = ["gemini-3.5-flash"]
```

مثال Groq:
```python
AI_KEY = "gsk_..."
AI_BASE = "https://api.groq.com/openai/v1"
AI_MODELS = ["llama-3.3-70b-versatile"]
```

> بمجرد وضع المفتاح يتحول البوت تلقائياً للوضع السريع بدون أي تعديل آخر.

## 🎨 تغيير بطاقة الترحيب

البطاقة موجودة في `assets/banner.png`. لتغيير الاسم أو الوصف فيها:

```bat
python assets\make_banner.py
```

أو عدّل النص في نهاية الملف:
```python
build(name="نوفا", tagline="مساعدك الذكي", handle="@vvfvq")
```

> إن حذفت البطاقة، يتحول البوت تلقائياً لرسالة نصية عادية.

## ⚙️ التخصيص السريع (`config.py`)

```python
BOT_NAME      = "نوفا"                 # اسم البوت
TAGLINE       = "مساعدك الذكي"          # الوصف
SUPPORT_URL   = "https://t.me/vvfvq"    # الدعم
CHANNEL_URL   = ""                      # رابط قناتك (اختياري)
DAILY_LIMIT   = 100                     # رسائل مجانية يومياً
COOLDOWN      = 2                       # ثانية بين الرسائل
STICKER_PACKS = ["UtyaDuck"]            # باكات الملصقات
MESSAGE_EFFECT = "5104841245755180586"  # تأثير /start (🔥)
```
