# 🚀 نشر البوت على استضافة مجانية 24/7

البوت جاهز للنشر: يدعم Docker، ويقرأ الأسرار من متغيرات البيئة، وفيه **Keep-Alive** يمنع الاستضافة من إيقافه.

---

## ما تحتاجه (مجاناً)

| الحساب | لماذا | بطاقة؟ |
|---|---|---|
| GitHub | لحفظ الكود | ❌ |
| Render | لتشغيل البوت | ❌ |

---

## الطريقة: Render (موصى بها)

### 1) ارفع الكود على GitHub (بدون Git — من المتصفح)

1. افتح https://github.com/new
2. اسم المستودع: `nova-bot` → **Private** → Create repository
3. اضغط **uploading an existing file**
4. فك ضغط `AIBot-deploy.zip` واسحب **محتويات المجلد** (كل الملفات) إلى الصفحة
5. اضغط **Commit changes**

> ⚠️ لا ترفع `.env` أبداً — فيه توكن البوت والمفتاح.

### 2) انشر على Render

1. افتح https://dashboard.render.com/ → **Sign in with GitHub**
2. **New +** → **Web Service**
3. اختر مستودع `nova-bot` → **Connect**
4. الإعدادات:
   - **Runtime**: `Docker`
   - **Instance Type**: `Free`
   - **Region**: `Frankfurt` (الأقرب)
5. أضف متغيرات البيئة (**Environment**):

| Key | Value |
|---|---|
| `BOT_TOKEN` | توكن البوت من BotFather |
| `AI_PROVIDER` | `gemini` |
| `AI_KEY` | مفتاح Gemini |

6. اضغط **Deploy Web Service** → انتظر 2–3 دقائق

✅ لما يظهر **Live** — البوت شغّال 24 ساعة، حتى لو طفيت جهازك.

---

## كيف يبقى شغّالاً بدون توقف؟

Render يوقف الخدمات المجانية بعد **15 دقيقة خمول**. لهذا أضفت:

- `RENDER_EXTERNAL_URL` (يوفره Render تلقائياً) → البوت يرسل لنفسه طلب كل **10 دقائق**
- سيرفر صحة على المنفذ `/` يعيد `OK`

النتيجة: الخدمة تبقى مستيقظة، وتستهلك أقل من 750 ساعة/شهر المسموحة.

## ملاحظات مهمة

| الموضوع | التفاصيل |
|---|---|
| قاعدة البيانات | تُمسح عند إعادة النشر (القرص مؤقت). حد الرسائل اليومي يعود صفراً — غير مؤثر عملياً |
| أول تشغيل | قد يأخذ 2–3 دقائق لبناء الحاوية |
| تحديث البوت | عدّل الملفات على GitHub → Render يعيد النشر تلقائياً |
| السجلات | تبويب **Logs** في Render |
| التوقف اليدوي | **Suspend** من اللوحة |
